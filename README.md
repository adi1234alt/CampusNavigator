# CampusNav-AI

CampusNav-AI is a web application that makes it easier to navigate around a university campus. It combines an interactive map with an AI assistant so users can quickly find buildings, hostels, cafeterias, sports facilities, and other important locations.

The project was developed using React, Vite, Leaflet, and the Google Gemini API as part of a hackathon to improve the campus navigation experience.

---

## Features

- Interactive campus map
- Search for campus buildings and locations
- Live location using browser geolocation
- AI chatbot for campus-related questions
- Responsive design for desktop and mobile
- Clean and simple user interface

## Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/CampusNav-AI.git
```

Move to the project folder

```bash
cd CampusNav-AI/client
```

Install dependencies

```bash
npm install
```

Create a `.env` file and add your Gemini API key

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```

Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
